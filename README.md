# SOS Admin

**Le guide de dépannage des techniciens IT** : une base de connaissances gratuite qui répertorie les problèmes rencontrés sur le terrain (postes Windows, Active Directory, Microsoft 365, réseau, impression…), avec pour chacun les symptômes, le diagnostic pas à pas, la résolution et la vérification.

- Interface graphique d'abord, ligne de commande en alternative.
- Étapes adaptées à la version (Windows 10 / 11, Windows Server…).
- Fonctionne hors ligne. Aucune donnée collectée.

> 🚧 Projet en construction : le site public et l'application iOS arrivent.

## Pour contribuer

Les fiches sont des fichiers YAML dans [`content/`](content/). Lire le [guide de rédaction](docs/guide-redaction.md), puis :

```bash
npm install
npm run validate
```

Une erreur dans une fiche ? Ouvrez une issue avec le modèle « Signaler une erreur dans une fiche ».
